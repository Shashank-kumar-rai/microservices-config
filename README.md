# Microservices Config

This repository contains centralized configuration files for the Spring Boot microservices project.

## Microservices
- User Service
- Hotel Service
- Rating Service

## Technology Stack
- Java
- Spring Boot
- Spring Cloud Config Server
- Spring Cloud Netflix Eureka
- GitHub

## Purpose
The Config Server fetches configuration files from this GitHub repository and provides them to the respective microservices.
